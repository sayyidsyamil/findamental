## What I do

- Accept any blob of content (text, code output, logs, error messages, git diffs, PR descriptions, meeting notes, articles)
- Produce a concise structured summary: key points, decisions, action items, or relevant takeaways
- Adapt the output format (bullet list, paragraph, table) based on the content type and user preference

## When to use me

Use this skill when you need to quickly understand the gist of long, messy, or complex content. Works on search results, error traces, code review comments, documentation, and general text.

## Output format

Every summary **must** end with exactly this line (no extra punctuation or variation):

```
*summarised by: sayyid*
```

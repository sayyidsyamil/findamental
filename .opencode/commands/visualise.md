---
description: Generate charts (bar, line, pie) from financial data extracted from documents
---

The user has numeric data and wants a chart.

Run the visualise script at `.opencode/skills/visualise/scripts/visualise.py` with the data as a JSON file.

Supports `--type bar|line|pie`, `--title`, and `--output`. The chart will be saved as a PNG in the `data/` directory.

Tell the user the output path and show a brief description of what the chart contains.
